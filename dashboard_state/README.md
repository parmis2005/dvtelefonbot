# Dashboard State

Dieser Ordner wird vom Backend automatisch aktualisiert, sobald im Dashboard
Konfigurationen, Kontakte, Prompts, Stimmen, Kampagnen oder Anrufdaten geändert
werden.

Die generierten JSON/Markdown-Dateien sind absichtlich in `.gitignore`
ausgeschlossen, weil sie Telefonnummern, E-Mail-Adressen, Transkripte und andere
personenbezogene Daten enthalten können. Sie bleiben lokal im VS-Code-Projekt.
